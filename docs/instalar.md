# Instalar en el móvil

1. En el móvil, abre: https://github.com/valenciaj/Sudoku/releases/latest/download/sudoku.apk
2. Se descarga `sudoku.apk`. Ábrelo desde la notificación o desde "Descargas".
3. Si Android avisa de "orígenes desconocidos", pulsa **Ajustes** y activa **Permitir de esta fuente** para el navegador. Vuelve atrás.
4. Pulsa **Instalar**.

Para actualizar, repite los pasos: se instala encima y no se pierden las partidas.

Nota: si el repositorio es privado, el enlace pide iniciar sesión en GitHub.
